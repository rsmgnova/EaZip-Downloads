# EaZip

EaZip is a modern macOS utility for compressing, extracting, and editing archives.

**Requirements:** macOS 13 Ventura or later on Intel or Apple silicon.

## Download

Download the latest installer from the [latest release](https://github.com/rsmgnova/EaZip-Downloads/releases/latest).

## Install

1. Download the DMG.
2. Open the DMG.
3. Drag **EaZip** to **Applications**.
4. Eject the disk image, then open EaZip.

EaZip is signed with a Developer ID certificate and notarized by Apple for Gatekeeper verification.

## Verify the download

The SHA-256 checksum is listed in each release. Calculate the downloaded file's checksum with:

```sh
shasum -a 256 ~/Downloads/EaZip-*.dmg
```

Compare the output with the checksum in the release notes.
